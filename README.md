# Muhammad Anas Shahid — AI/ML Engineer Portfolio

[![Vite](https://img.shields.io/badge/Vite-5.4-646CFF?style=flat-square&logo=vite)](https://vitejs.dev/)
[![Three.js](https://img.shields.io/badge/Three.js-3D_Graphics-black?style=flat-square&logo=three.js)](https://threejs.org/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

A modern, responsive, high-performance portfolio web application for **Muhammad Anas Shahid** featuring a 3D neural network background, interactive code editor mockup, custom AI Chatbot assistant, and sleek dark glassmorphism design.

---

## ✨ Features

- 🧠 **3D Neural Network Background**: Built using Three.js with floating nodes and dynamic particle connections.
- ⚡ **Interactive Code Editor Box**: Tab switching between Python RAG pipelines, agent orchestrators, and MCP servers with syntax highlighting.
- 🤖 **Anas AI Assistant**: Client-side AI Chatbot answering questions about Anas's projects, tech stack, COMSATS education, and business growth background.
- 🎯 **Filterable Projects Grid**: Category filtering across AI & GenAI, Software & Systems, and Products.
- 🎓 **Academic & Certification Showcase**: Highlighting Software Engineering at COMSATS Lahore & Prompt Engineering certification from Dubai Future Foundation.
- 📩 **Contact Modal & Direct Links**: Direct email, phone, and pop-up contact form modal.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Glassmorphism system), JavaScript (ES6 Modules)
- **3D & Visuals**: Three.js, FontAwesome Icons, Outfit & Fira Code Fonts
- **Build Tool**: Vite

---

## 🚀 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/anas-shahid-portfolio.git
   cd anas-shahid-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start dev server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
